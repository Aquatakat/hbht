# Flags, the journal and the quest atlas (roadmap 1E)

`GameStateFunnelTable` (`HBHT.Rom.Db`) reads the flag network. The engine code that sets and reads flags is listed in [code tables](code-tables.md#flags); the port of the network, its evaluation and what the engine writes into flags is in [flags](../systems/flags.md).

The quest atlas is `QuestIndex` (`HBHT.Plugins`) over the installed plugins' records: `hbht flag <flag>...` prints what sets, clears and reads a flag, with the nearest dialogue line and where each script is started, and the editor's Atlas tab browses it ([editor](../systems/editor.md)). It cross-references the dialogue ops, script done and battle flags, map objects, shops, key items, members, the chunks' world map regions, the flag network, the journal and the state flags record. It doesn't record what engine code reads and writes beyond those (battles' boss flags, the cinematics', the world map's pieces', the minimaps' and the camp scenes'), nor the scripts code starts, such as the help menu and the death scenes. The importer names the flags those engine tables hold, such as "Brenna is in the party", as the flag records' labels (`FlagLabels`, `HBHT.Rom.Quests`).

- **Derived flags:** each has a kind (logic, value or count), an operation, an operand and its inputs. Logic flags are AND, OR, exactly-one (EOR), none (NOT) or "inputs as bits equal the operand" (MSK). Value flags compare the inputs as bits, and count flags compare how many are set, using ==, >, < or !=. Inputs of 0xFFFF are skipped. How they're evaluated is [flags](../systems/flags.md#the-network)'.
- **Engine state as flags:** the calendar, rain and terrain are written into flags 2299–2324, and 2325–2369, the party's best stats and skills, are laid out but never written ([flags](../systems/flags.md#what-the-engine-writes)).
- **The journal:** entry *i* has flag 5556 + *i*, which is "entry *i*'s flag is set". When a flag from 5556 up turns on, the game raises flag 3617 and shows the new-entry notice ([flags](../systems/flags.md)).
- **Flags nothing sets:** besides those engine code sets ([code tables](code-tables.md#flags)), 955–958 and 960–963 have no setter but Ehud's underground's secret doors ([maps](maps.md#map-objects-in-the-base-plugin-06)).
- **Reading flags from a checkpoint:** `gameStates` (1.0: `0x800DAF00`) points to the loaded `GameStateFunnel`. Its word at +8 points to the 8-byte flag entries, and each entry's byte at +6 is the flag's current value.
