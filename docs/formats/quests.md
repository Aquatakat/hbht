# Flags, the journal and the quest atlas (roadmap 1E)

The engine code that sets and reads flags is audited in [hardcoded-content.md](../hardcoded-content.md). The port of the flag network (2.1) is in [flags](../systems/flags.md).

`aidyn atlas <rom>` writes `out/<version>/atlas/atlas.json`, and `aidyn flag <rom> <flag>...` prints what sets and reads a flag, with the nearest dialogue line and where each script is started. To browse it, use the editor's Atlas tab and flag pages, which rebuild it over the imported plugins (see [inspector](../systems/inspector.md)). The atlas shows each flag's setters and readers and each script's nodes, and draws what leads to an item (upstream) or what it leads to (downstream). For example, flag 285 shows that the lighthouse key comes from the keeper's conversation, and that the keeper only appears once derived flag 5349 holds. The atlas cross-references the dialogue ops, script done flags, map objects, the flag network and the flags engine code reads and writes (1H). Engine code also names many flags, such as "Brenna is in the party", and the editor shows these names.

- **The flag network:** derived flags are evaluated in index order until nothing changes. Logic flags are AND, OR, exactly-one (EOR), none (NOT) or "inputs as bits equal the operand" (MSK). Value flags compare the inputs as bits, and count flags compare how many are set, using ==, >, < or !=. Inputs of 0xFFFF are skipped. Evaluating the network from each checkpoint's plain flags reproduces every derived flag in its RAM, in all four checkpoints.
- **Engine state as flags:** the calendar, rain and terrain are written into flags 2299–2324 (see [flags](../systems/flags.md)). Flags 2325–2369, the party's best stats and skills, are never written, because their setters' table lookup always fails. The derived flags that compare them with thresholds (5287–5346) never turn on, so a secret teleporter in EhudUnder M05 and three dialogue objects in EhudUnder G03 never work.
- **The journal:** entry *i* has flag 5556 + *i*, which is "entry *i*'s flag is set". When a flag from 5556 up turns on, the game raises flag 3617 and shows the new-entry notice.
- **Coverage, checked against the checkpoints:** 2,031 plain flags have a setter in the data, and 140 are read but never set by data. Of the roughly 560 flags set in the late checkpoints, only 49 have no known setter. They were 3, 154, 456, 458, 533, 566, 686, 689, 692, 697, 788–805, 955–958, 960–963, 3404, 3426, 3428, 3432, 3611, 3612 and 3733–3739. 1H found engine code that sets all but 955–958 and 960–963, which are secret doors in Ehud's underground (see [hardcoded-content.md](../hardcoded-content.md)).
- **The Gwernia opening reads as a chain:** the Kendall cut-scene (Borg13 866) sets done flag 5. Derived flag 5423 is "5 set, 9 and 47 clear", and it enables the Shadow and the `stagenorth` scene (868). 5033 is "5 set, 55 and 47 clear", and it enables Gotzone and Zurene. The ambush cut-scene (869) sets 11, its scripted fight sets 978 (the party loses it by design), and Oriana's conversation (916) sets 50, journal entry 1.
- **Scripts:** 79 scripts aren't started by any map object or script. Code starts some of them, such as the help menu and the death scenes.
- **Reading flags from a checkpoint:** `gameStates` (1.0: `0x800DAF00`) points to the loaded `GameStateFunnel`. Its word at +8 points to the 8-byte flag entries, and each entry's byte at +6 is the flag's current value.
